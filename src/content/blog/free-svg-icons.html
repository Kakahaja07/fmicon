What makes an SVG icon truly free to use?

An SVG icon is free to use when its licence allows your kind of project without payment. Permissive licences such as MIT, ISC and CC0 let you use icons commercially with no credit in your interface.

Here's something most people don't know. "Free" on an icon site often means free to download, not free to use any way you like. The licence is what counts.

  • MIT and ISC. Both are approved by the Open Source Initiative. You can use, change and sell work that includes the icons. You keep the licence text with the source files, not in your app.
  • CC0. Creative Commons Zero puts work in the public domain. No conditions at all.
  • CC BY 4.0. Creative Commons says this licence requires attribution. You must credit the author wherever you use the icons, which many teams forget.
  • "Free for personal use". Not free for a business site. Skip these for client work.

fmicon uses the MIT licence. That means every icon is free for personal and commercial work, with no sign-up and no credit needed on your site.

How do you pick a good free SVG icon set?

Pick one icon set that has a consistent grid, a consistent stroke, enough icons for your whole product, and the formats you need. Consistency matters more than any single icon.

I use this short checklist before I commit to a set:

  1. One grid. Icons should share the same canvas, usually 24 by 24 px. fmicon draws every icon on a 24 px grid, so they line up in a row.
  2. One stroke weight. Line icons should use the same stroke, such as 1.5 px. Mixed strokes are what made my friend's footer feel off.
  3. Enough coverage. Search for the ten icons you need most, like home, search, settings and lock. If three are missing, keep looking.
  4. More than one style. Having a filled version of each outline icon makes active states easy. fmicon ships 8 styles, from linear to duotone.
  5. The formats you need. Raw SVG for the web, PNG for email, and packages if you use React, Vue or Svelte.
  6. Recent updates. Check the GitHub repository. A set that is still maintained will keep growing with you.

How do you add free SVG icons to a website?

There are three easy ways to add free SVG icons to a website: paste the SVG code inline, load the file with an img tag or CDN link, or install an icon package from npm. Each takes under five minutes.

Option 1: Paste the SVG inline

Copy the SVG code from an icon page, such as the home icon, and paste it into your HTML. Inline SVG is the most flexible option, because CSS can reach inside it.

<a href="/" class="nav-link">
  <svg width="20" height="20" viewBox="0 0 24 24" fill="none" aria-hidden="true">
    <path d="..." stroke="currentColor" stroke-width="1.5" />
  </svg>
  Home
</a>

Option 2: Link the file from a CDN

A CDN (content delivery network) serves files from servers close to your visitors. fmicon hosts every icon at cdn.fmicon.dev, so you can link it without downloading anything.

<img src="https://cdn.fmicon.dev/svg/linear/search-normal.svg" alt="Search" width="24" height="24">

This is the quickest way to try icons in a prototype or a no-code builder. The trade-off is that you cannot recolour an img with CSS. The raw SVG and CDN docs list every path.

Option 3: Install a package

If your site uses a framework, a package is the cleanest option. You import icons as components and set size and colour with props.

npm i fmicon-react   # or fmicon-vue, fmicon-svelte, fmicon

Our React icons guide covers this step by step, and the docs cover every framework.

How do you change the colour of a free SVG icon?

You change the colour of an SVG icon by setting the CSS color of its parent, as long as the icon uses currentColor. For an icon in an img tag, you need a different file or a CSS filter instead.

MDN Web Docs explains that currentColor takes the value of the element's color property. So this one rule turns every inline icon in your navigation blue:

.nav-link { color: #1265ec; }
.nav-link:hover { color: #0b4fc0; }

This is genuinely one of my favourite things about SVG. Your icons follow your brand colours and hover states with zero extra files. You can also test colours live on any icon page before you copy the code.

Do free SVG icons slow down a website?

No, well-made SVG icons barely affect page speed. A typical line icon is under 1 KB, and servers compress SVG further because it is plain text.

I measured all 891 linear icons in fmicon. They average 878 bytes (0.86 KB) each. The home icon drops from 541 to 300 bytes with gzip. Twenty icons on a page add less weight than one small photo.

Two habits keep them fast. Set width and height on every icon so the layout does not jump while loading. And only load the icons a page uses, which packages do for you. Our SVG vs PNG test shows the full numbers.

Frequently Asked Questions

Can you use free SVG icons for commercial projects?

Yes, you can use free SVG icons for commercial projects when the licence allows it. MIT, ISC and CC0 licences all permit commercial use. fmicon uses the MIT licence, so its 1,021 icons work in client sites, apps and products you sell, with no fee and no sign-up.

Do you need to credit free icons on your website?

No, you do not need to credit icons under MIT, ISC or CC0 licences on your website. Icons under CC BY 4.0 do need visible credit to the author. With MIT icons such as fmicon, you only keep the licence text in your source code, not in your interface.

How do you download an SVG icon?

You download an SVG icon by opening its page in an icon library and clicking the SVG download or copy button. On fmicon, every icon page lets you pick a style, size and colour, then copy the SVG code, download the file, or copy a CDN link.

Are SVG icons good for SEO?

SVG icons help SEO indirectly by keeping pages light and fast, which supports good Core Web Vitals scores. Google can also index SVG files as images. Icons themselves rarely rank, so give important images descriptive alt text and keep decorative icons hidden from screen readers.

Can you edit free SVG icons in Figma?

Yes, you can edit free SVG icons in Figma. Paste the SVG code or drag the file onto the canvas, and Figma turns it into editable vector layers. You can then change stroke width, colour and shape, as long as the icon's licence allows changes, which MIT does.
